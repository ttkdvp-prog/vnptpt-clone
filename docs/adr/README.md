# Architecture Decision Records (ADR)

Quyết định kiến trúc quan trọng của An Hưng Thịnh ERP. Mỗi ADR trả lời: **Context → Options → Decision → Consequences**.

| ID | Title |
|----|-------|
| [0001](./0001-nextjs-app-router.md) | Next.js App Router |
| [0002](./0002-authjs.md) | Auth.js Credentials |
| [0003](./0003-prisma.md) | Prisma on PostgreSQL |
| [0004](./0004-zustand.md) | Zustand for UI state |
| [0005](./0005-react-query.md) | TanStack Query for server data |
| [0006](./0006-hono-route-handlers.md) | Hono Route Handlers (not Server Actions yet) |

## Template

```md
# NNNN — Title

## Status
Accepted | Superseded | Deprecated

## Context
Vấn đề / ràng buộc.

## Options
1. …
2. …

## Decision
Quyết định cuối.

## Consequences
- Tích cực
- Chi phí / rủi ro
```
